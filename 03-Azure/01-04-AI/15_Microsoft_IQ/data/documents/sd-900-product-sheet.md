## 1. What it is

1.1 The SD-900 is Strandvik's heavy-duty drive unit: a motor and gearbox in one housing that moves large machines such as truck body presses, crushers, paper machines, rolling mills and port cranes. It is built at the Strandvik factory in Pune, India.

## 2. Key data

| Item | Value |
|---|---|
| Rated power | 900 kW |
| Output torque | 285 kNm |
| Weight on transport frame | about 4.2 tonnes |
| Serial format | SD9-X-NNNN (for example SD9-P-0981) |
| Factory test | Full load test before shipping |
| Design life | 60,000 operating hours |

## 3. Compatibility

3.1 The SD-900 drive unit replaces SD-900s only (not SD-700). The mounting flange, shaft and control interface are different.

3.2 The smaller SD-700 (serial format SD7-X-NNNN) is a separate product and cannot replace an SD-900, even for a short time.

## 4. Installation

4.1 Installation takes 6 to 8 hours and needs a certified technician. The technician must hold the Strandvik SD-900 certificate.

4.2 The customer provides crane access and a lockout of the machine for the installation window.

4.3 After installation the technician runs a test at reduced load, then at full load, and signs the commissioning record.
